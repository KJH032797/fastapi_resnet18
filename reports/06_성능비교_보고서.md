# 성능 측정 및 비교

측정 입력은 Validation에서 무작위 선택한 서로 다른 이미지 5장이다. 각 이미지에 대해 동기 MISS/HIT와 비동기 MISS/HIT를 순차 측정했다. MISS 그룹 시작 전에 Redis DB 1에서 선택된 다섯 이미지의 키만 지웠다. 각 조건은 5회이며, 비동기 완료시간은 100ms 간격으로 상태를 조회해 `done`을 확인한 시점까지다.

## 중앙값

| 경로 | 캐시 | 횟수 | HTTP 접수/응답 중앙값 | 전체 완료 중앙값 | 추론 중앙값 |
|---|---|---:|---:|---:|---:|
| 동기 | MISS | 5 | 21.37ms | 21.37ms | 16.82ms |
| 동기 | HIT | 5 | 1.71ms | 1.71ms | 해당 없음 |
| 비동기 | MISS | 5 | 7.75ms | 113.28ms | 18.55ms |
| 비동기 | HIT | 5 | 8.76ms | 116.80ms | 해당 없음 |

비동기: 접수 응답 후 Worker 처리·상태 조회를 거쳐 완료. 접수시간과 전체 완료시간 구분. 단일 worker 결과만으로 모델 추론 속도 향상 판단 불가. HIT는 추론 생략, 추론시간 해당 없음.

## 측정 범위와 파일

측정 범위: Validation 이미지 5장, 각 조건 5회 반복. 모델 정확도·Test 성능 평가 아님. 결과 항목: 이미지 경로·해시, 요청 응답·완료·추론 시간, 예측, Job ID.

- 원본 CSV: [`data/timings_validation_benchmark_5x.csv`](data/timings_validation_benchmark_5x.csv)
- 상세 JSON: [`evidence/performance_validation_benchmark_5x.json`](evidence/performance_validation_benchmark_5x.json)

측정 환경·범위: CPU, 단일 worker. 동시 사용자 부하·다른 장치 성능으로 일반화 불가.
