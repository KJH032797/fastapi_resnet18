# DB 구조 및 작업 이력

- DB: PostgreSQL
- 테이블: `image_jobs`
- 확인한 컬럼: `id`, `image_path`, `status`, `model_id`, `top1_label`, `top1_score`, `all_scores`, `inference_ms`, `cache_hit`, `error_message`, `created_at`, `updated_at`.
- `image_path`에는 원본 파일명이 아니라 업로드 이미지 바이트를 보관하는 UUID `.bin` 파일명이 저장.
