## 시스템과 API

- Docker Compose 구성: FastAPI `web`, Celery `worker`, Redis, PostgreSQL.
- 동기 API: 캐시 조회 후 결과 즉시 반환.
- 비동기 API: HTTP 202와 Job ID 먼저 반환. Worker 처리 후 결과를 DB에 저장.
- Redis HIT: 모델 추론 생략.
- 구조 문서: [02 시스템 아키텍처](02_시스템_아키텍처.md), [03 API 명세서](03_API_명세서.md), [04 DB 구조·작업 이력](04_DB_구조_작업이력.md), [05 AI 버튼 처리 흐름](05_AI버튼_처리흐름.md).

## 개선 방향과 판단

- 우선 개선 대상: 병든 잎 → healthy 오분류. 병든 잎을 놓칠 가능성 고려.
- 병해 근거: 각진잎반점병과 콩녹병의 증상·관리는 다름. 일부 방제 방법은 겹치지만 완전 대체 관계 아님. 상세 근거는 [09 모델 개선 실험 결과 및 검토](09_model_improvement_plan.md).
- 남은 병든 클래스 간 오분류: 점수 차이가 컸고, 육안상 혼동 가능한 사례 확인.
- 남은 병든 잎 → healthy 사례와 Train 유사 조건 검토. 원인 및 추가 조치 효과 확정 불가.
- 판단: 후보 성능과 잔여 시간 고려. 추가 학습·임계값 조정 미시행.
- 미구현·미측정: HSV·Mask 후처리, Grad-CAM, CNN+ML 결합.
- 현재 서비스 모델: `artifacts/beans_resnet18_full`. Validation 동기·비동기 재검증 완료.
